## 一、核心概念澄清

### 1.1 什么是"完全自举"？

**完全自举 (Bootstrapping)** 是指编程语言能够用自身编译自身的过程。

**标准定义**：
1. 存在一个编译器（或汇编器）用目标语言编写
2. 这个编译器可以编译自身的源代码
3. 存在一个最小可信计算基 (TCB) 来启动这个过程

### 1.2 最小可信计算基 (TCB)

**关键理解**：没有任何编程语言可以完全"凭空"存在。每种语言都需要一个启动层：

| 语言 | TCB（启动层） | TCB 大小 | 说明 |
|------|--------------|----------|------|
| C | 汇编语言 | ~1000 行 | 汇编是机器码的助记符 |
| Java | C++ (JVM) | ~100,000 行 | 需要 C++ 编写的虚拟机 |
| Python | C (CPython) | ~500,000 行 | 需要 C 编写的解释器 |
| Rust | C++ (LLVM) | ~1,000,000 行 | 需要 C++ 编写的编译器后端 |
| **Evomorph** | **C 虚拟机** | **~1500 行** | **所有语言中最小的 TCB 之一** |

### 1.3 "不依赖任何语言"的实际含义

**正确理解**：
- ❌ 不是"完全不依赖任何东西"（这在物理上不可能）
- ✅ 而是"不依赖其他高级语言"
- ✅ 编译器本身用目标语言编写
- ✅ TCB 是最小的、可审计的

**Evomorph 的实现**：
1. **编译器**：用 Evomorph 编写（或 EvoASM 简化汇编）
2. **运行时**：C 虚拟机（~1500 行，可手工审计）
3. **自举**：编译器可以编译自身

### 3.3 ✅ 阶段 2：EvoASM 汇编器

**文件**：`bootstrap/full/evoasm_assembler.py`

**关键特性**：
- ✅ **简化汇编语法**，直接对应指令
- ✅ 支持所有 **64 条指令**
- ✅ 支持 **寄存器、立即数、系统调用常量**
- ✅ **指令编码**：4 字节/指令

**语法示例**：
```
; 注释以分号开头
ABOUND R0, 5       ; R0 = 5
ABOUND R1, 10      ; R1 = 10
INCREASE R0, R1     ; R0 = R0 + R1 = 15
ABOUND R0, EXIT     ; 系统调用：退出
RECV R0, 0          ; 调用系统调用
HALT                ; 停止
```

**指令编码格式**：
```
每条指令 4 字节：
byte1: ((opcode & 0x3F) << 2) | ((modifier >> 4) & 0x03)
byte2: modifier & 0x0F
byte3: operand1 (寄存器或立即数)
byte4: operand2 (寄存器或立即数)
```

**编译验证**：
```bash

# 汇编成功，生成原始字节码
```

### A. 六十四卦指令集（核心）

| 卦象 | 助记符 | 操作码 | 功能 |
|------|--------|--------|------|
| ䷀ | CREA | 63 | 创建新进程/线程 |
| ䷁ | RECV | 0 | 接收消息/系统调用 |
| ䷶ | ABOUND | 13 | 加载立即数 |
| ䷩ | INCREASE | 49 | 加法 |
| ䷨ | REDUCE | 35 | 减法 |
| ䷈ | SHL | 56 | 左移 |
| ䷉ | STEP | 59 | 步进 |
| ䷋ | HALT | 0 | 停止 |

### B. 系统调用列表

| 调用号 | 名称 | 参数 | 功能 |
|--------|------|------|------|
| 0 | OPEN | R1=filename, R2=mode | 打开文件 |
| 1 | READ | R1=fd, R2=buf, R3=count | 读取文件 |
| 2 | WRITE | R1=fd, R2=buf, R3=count | 写入文件 |
| 3 | CLOSE | R1=fd | 关闭文件 |
| 10 | MALLOC | R1=size | 分配内存 |
| 20 | STRLEN | R1=str | 字符串长度 |
| 40 | PRINT | R1=str | 打印字符串 |
| 255 | EXIT | 无 | 退出程序 |

### C. EvoASM 语法规范

#### 注释
```
; 单行注释以分号开头
```

#### 指令格式
```
助记符 操作数1, 操作数2
```

#### 操作数类型
1. **寄存器**：`R0` - `R15`
2. **立即数**：
   - 十进制：`5`, `10`, `255`
   - 十六进制：`0x05`, `0xFF`
   - 二进制：`0b101`
3. **系统调用常量**：`OPEN`, `READ`, `WRITE`, `EXIT` 等

#### 示例
```
; 加载立即数
ABOUND R0, 5       ; R0 = 5
ABOUND R1, 0x0A    ; R1 = 10

; 算术运算
INCREASE R0, R1     ; R0 = R0 + R1
REDUCE R0, R1       ; R0 = R0 - R1

; 系统调用
ABOUND R0, PRINT    ; 系统调用号 40
ABOUND R1, 0x100000 ; 字符串地址
RECV R0, 0          ; 调用系统调用

ABOUND R0, EXIT     ; 退出
RECV R0, 0

HALT                ; 停止
```

### D. 指令编码示例

**指令**：`ABOUND R0, 5`

**编码过程**：
```
opcode = 13 (ABOUND)
modifier = 0
operand1 = 0 (R0)
operand2 = 5 (立即数)

byte1 = ((13 & 0x3F) << 2) | ((0 >> 4) & 0x03)
      = (13 << 2) | 0
      = 52 = 0x34

byte2 = 0 & 0x0F = 0 = 0x00

byte3 = 0 = 0x00

byte4 = 5 = 0x05

编码结果：34 00 00 05
```

**验证**：
```
反汇编：
00000000 34 00 00 05    ABOUND       R0, R5
```
